# INCIDENT RESPONSE PLAN (IRP)

### Phases
1. **Preparation:** Regular tabletop exercises.
2. **Identification:** SOC alerts and triage.
3. **Containment:** Isolate affected endpoints from the network.
4. **Eradication:** Remove malware/vulnerability.
5. **Recovery:** Restore from clean backups.
6. **Lessons Learned:** Post-incident review meeting.
