# RELEASE NOTES

**Application:** Mobile App (iOS & Android)  
**Version:** 4.5.0  
**Release Date:** July 21, 2026  

### 🎉 New Features
*   **Dark Mode Support:** The app now fully supports system-wide dark mode settings.
*   **Biometric Login:** Added support for FaceID (iOS) and Fingerprint authentication (Android) for faster logins.
*   **In-App Chat:** Users can now contact customer support directly from the settings menu.

### 🐛 Bug Fixes
*   Fixed an issue where the shopping cart badge would not update immediately after adding an item.
*   Resolved a crash that occurred when navigating to the profile page without an active network connection.
*   Fixed UI clipping issues on smaller screen devices (e.g., iPhone SE).

### ⚠️ Known Issues
*   Push notifications may be delayed by up to 2 minutes on certain Android 14 devices. A patch is scheduled for version 4.5.1.
